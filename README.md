Forecasts each Grand Theft Auto VI trophy's earn rate on Exophase at 2026-11-26. It models earners and players tracked as separate counts: an age model over the players-tracked trajectory (two progression-curve families per trophy) for a moving history, and a refresh-jump branch for a frozen launch-night page, where Exophase's counts lag behind the game.

## Run it

```sh
python3 main.py
```
